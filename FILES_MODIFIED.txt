USAGE EXAMPLES
================================================================================

BASIC USAGE (Local Only)
$ python app.py --days 5

WITH S3 UPLOAD
$ export AWS_ACCESS_KEY_ID=your_key
$ export AWS_SECRET_ACCESS_KEY=your_secret
$ export DOCS_S3_BUCKET=documents-churn
$ python app.py --days 5

WITH CUSTOM PARAMETERS
$ python app.py \
    --days 10 \
    --min-new-docs 3 \
    --max-new-docs 8 \
    --seed 42 \
    --s3-bucket my-docs-bucket \
    --aws-region us-west-2

PYTHON API
from s3_storage import S3DocumentStorage

storage = S3DocumentStorage("my-bucket")
result = storage.upload_document("DOC-001", "content", day=1)
versions = storage.get_document_versions("DOC-001")
storage.create_version_tag("DOC-001", "approved")

================================================================================
NEXT STEPS FOR DEPLOYMENT
================================================================================

1. Create S3 bucket
   $ aws s3 mb s3://documents-churn

2. Enable versioning (automatic in code, but can be manual)
   $ aws s3api put-bucket-versioning \
     --bucket documents-churn \
     --versioning-configuration Status=Enabled

3. Set up IAM user with S3 permissions
4. Export AWS credentials
5. Run application
   $ python app.py --days 5

6. Verify in S3
   $ aws s3 ls s3://documents-churn/ --recursive
   $ aws s3api list-object-versions --bucket documents-churn

================================================================================
MONITORING & MAINTENANCE
================================================================================

View all versions of a document:
$ aws s3api list-object-versions --bucket documents-churn

Get specific version:
$ aws s3api get-object --bucket documents-churn \
  --key docs/day1/LOG-123.txt \
  --version-id v1234567890 \
  output.txt

Check bucket size and version count:
$ aws s3api list-object-versions --bucket documents-churn \
  --query 'length(Versions)' | wc -l

Cost optimization - Set lifecycle policies:
$ aws s3api put-bucket-lifecycle-configuration \
  --bucket documents-churn \
  --lifecycle-configuration file://lifecycle.json
